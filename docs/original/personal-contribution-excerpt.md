           Booking Activity Analysis Overview:

The Python program analyses the booking data, through visual representation it provides analysis based on weekly booking activities. The program accepts the CSV file path and processes booking data from the given CSV file. The program calculates a series of data processing methods, specifically, it generates visualizations, statistical analysis and produces an Excel report with information obtained from the inputted data. 

User Engagement: The program downloads the bar graph and Excel report into two separate folders. Automatically creates and names them Images and reports if the folders don’t exist and then downloads the bar graphs into the images folder and Excel reports into the reports folder. This feature provides the user to have better analytical experience.
